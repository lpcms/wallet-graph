# graph

Фронтенд Wallet Graph на Next.js: граф связей кошельков (Sigma.js + ForceAtlas2) и прогноз цены.

```bash
cp .env.example .env.local   # адрес API, по умолчанию http://localhost:3001
npm install
npm run dev                  # http://localhost:3000
```

Описание всего проекта, API и команд — в [README в корне репозитория](../README.md).
